# Intimacy Jar

A [Chickadee Bandit](https://chickadeebandit.com/app-library/intimacy-jar) app.

A shared jar of ideas for couples — add activities and scenarios privately, then draw one at random for spontaneity.

## Features

- One shared jar; both partners add to it.
- Categories: romantic, playful, adventurous, intimate, other.
- Draw an idea at random when you cannot decide.
- Mark an idea tried, rate it, and add a note.
- Reciprocal partner setup; visible to nobody else in the household. Adults only.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-intimacy-jar/releases/latest/download/bundle.json
```
